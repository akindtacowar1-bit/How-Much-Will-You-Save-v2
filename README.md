# Cost of living savings calculator (Victorian Labor style, toll and fare caps only)

An unofficial calculator that estimates yearly savings from Victorian Labor's $30 toll cap and $30 public transport fare cap. Each vehicle and traveller is entered separately.

- `index.html` is the calculator.
- `.nojekyll` tells GitHub Pages to serve the files as they are.

## Restyling

The colours and fonts are set in the `:root` block at the top of the `<style>` section in `index.html`. Change `--red`, `--navy`, `--disp` and `--body` to match the official brand exactly.

## Authorisation

Add your own authorisation statement in the footer of `index.html`. There is a comment showing where. The official party website's authorisation line must not be copied, because it names a different person and organisation.

## Publish on GitHub Pages

1. Create a new public repository on GitHub.
2. Upload the files in this folder (not the folder itself) so `index.html` sits at the top level.
3. Go to **Settings > Pages**, set **Source** to **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. Your site will be at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/` within a few minutes.

Figures are estimates based on published Labor commitments and depend on Labor being re-elected.
